# 策略名稱
S00X - 範例：20~100元趨勢回檔多方

# 策略格式
- 進場策略：開盤前_全部 + 開盤前_部分N個 + 盤中_全部 + 盤中_部分N個 四段 AND
- 出場策略：停損/停利/持有 OR 開盤前_全部 OR 開盤前_部分N個 OR 盤中_全部 OR 盤中_部分N個

# 進場條件格式
- 開盤前_全部: [來自_pre]
    - 範例：股價_20_100.md
    - 範例：非KY非處置.md
    - 範例：開盤前_量大於_1000張.md

- 開盤前_部分N個: 符合 2 個 (N=2)
    - [來自_pre]：收盤價_站上_月線.md
    - [來自_pre]：RSI_50_以上.md
    - [來自_pre]：近20日_新高.md

- 盤中_全部: [來自_intraday]
    - 範例：開盤價_大於_昨日收盤.md

- 盤中_部分N個: 符合 1 個 (N=1)
    - [來自_intraday]：盤中_突破_昨日高點.md
    - [來自_intraday]：盤中_量能_大於_昨日同時段.md

# 出場條件格式
- 停損: 8%, 停利: 25%, 持有: 20日
    - 說明：單檔最大20%，避免過度集中，成本內建已含，額外注意滑價

- 開盤前_全部: [來自_pre]
    - (可空) 範例：轉弱警示_月線跌破.md

- 開盤前_部分N個: 符合 1 個 (N=1)
    - [來自_pre]：收盤價_跌破_月線.md
    - [來自_pre]：連續2日_收黑.md

- 盤中_全部: [來自_intraday]
    - (可空)

- 盤中_部分N個: 符合 1 個 (N=1)
    - [來自_intraday]：盤中_跌破_昨日低點.md

# 預期邏輯
- 為什麼這樣組？
    1. 股價20~100過濾低價飆股和高價股，符合公約第2條
    2. 開盤前_全部先用基本面+流動性過濾，避免訊號太多 (避開 S_DEAD_001 的坑：單純收盤價>=50 + 上漲 太寬鬆)
    3. 開盤前_部分 要求月線+RSI，抓趨勢不追漲停，符合禁止「當日收盤觸及漲停才買」
    4. 盤中_部分 用突破確認，避免未來函數
- 避免什麼坑？
    - 未來函數：全部用開盤前或盤中即時條件，不用收盤後才知道的
    - 漲跌停陷阱：不用「收盤價=漲停價」這種條件買進
    - 訊號過多：透過「部分N個」控制，不是全部都要符合

# 績效判讀
- 目標：ROI > 15%, 勝率 > 40%, 筆數 100-600
- 基準：大盤 31.6% (2026/03-09)，輸大盤 = 不及格
- 觀察：月報酬是否穩定，若像截圖 8月 -1.74% / 9月 -1.40% 連續轉弱 = 失效
